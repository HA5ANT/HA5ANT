## Security tooling

| Project | What it does |
|---|---|
| [**Wordlist-Indexer**](https://github.com/HA5ANT/Wordlist-Indexer) | Rust CLI (`wl`) that indexes, fuzzy-searches, and dedupes large wordlist collections — sub-5ms lookups, pipes straight into `ffuf`/`hashcat`/`gobuster`. |
